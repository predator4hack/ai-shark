# UI Changes

**Objective**: The task is migrate(smooth transition) streamlit based UI to a react framework based UI.

## Implementation Details

1. Analyse the project and understand the workings, you can start with streamlit_app.py. Try to understand the different phases, for example pitch-deck/additional documents upload, document processing, founders simulation and final memo preparation.

2. You need to create a react based UI, which should look minimal/premium. However you need to make sure not to hamper the existing streamlit UI yet. Come up with a strategy that supports both UIs, once the react based UI is finalized, we can chunk the streamlit UI.
